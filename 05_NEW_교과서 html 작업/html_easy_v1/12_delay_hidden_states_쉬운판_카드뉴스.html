세션 12 · Effect Compartment·지연·숨은 상태 · 쉬운판

농도와 효과가 어긋날 때
늦음을 만드는 시계는 어디 있나

농도는 떨어지는데 효과는 늦게 따라옴 — 그 늦음의 정체를 다리·수조·릴레이 셋으로 가려내는 노트

관통 척추 농도-효과가 어긋나는(hysteresis) 이유는 둘 사이에 숨은 상태(hidden state)가 끼어서임. 그게 분포 지연(effect compartment·다리)이냐, 신호 지연(transduction·릴레이)이냐, 내성(tolerance·수조+자동조절기)이냐를 가려내는 게 이 세션임.

"지연은 메커니즘이 아니다. 지연되는 상태에 이름부터 붙여라."

Gabrielsson & Weiner 5판 §3.9–3.14 (사례 PD13·PD20·PD21·PD35) · Rowland & Tozer 5판 Ch.8 — 모든 수치·인용 원문 대조

§1한 장 지도 · 관통 척추

관찰 하나, 4막의 추적

농도-효과 데이터를 그리면 고리(loop)가 보임. 그 고리 뒤의 숨은 상태가 누구인지 4막으로 추적함.

[관찰] 농도와 효과가 시간상 떨어져 있다 hysteresis loop
  │
  ├─ 1막 §4 loop 방향(CCW/CW)으로 후보 좁히기  ← 필터지 판결 아님
  ├─ 2막 §5 "약물 시계"인가? → Effect compartment, \(k_{e0}\)  ← 다리 통행
  ├─ 3막 §6 "시스템 시계"인가? → 내성/반동, Moderator \(M\)  ← 수조+조절기
  └─ 4막 §7 "신호 시계"인가? → Transit chain, \(n\times\tau\)  ← 릴레이 경주
🦴 척추 선언

농도-효과 어긋남은 둘 사이 숨은 상태가 끼어서임. 그게 분포 지연이냐, 신호 지연이냐, 내성이냐를 가려내는 게 이 세션 전부임. 막 넷을 본 뒤 감별표(§8)→NONMEM(§9)→진단 시그니처(§10)→혼동쌍(§11)→큰 그림(§12)→요약(§13)으로 마감함.

"식(ODE)을 고르는 건 그다음이다. 지금 늦는 게 누구냐를 먼저 묻는다."

§2도입 · 척추를 실제 약으로

같은 표적인데 회복 속도가 100배

수술 끝 무렵 마취과 의사의 고민 — "약을 지금 끌까?" 둘 다 μ-opioid 수용체(통증·의식을 누르는 단백질)에 똑같이 붙는 약인데:

Remifentanil · 끄면1분이면 깸
vs
Morphine · 끄면2시간 못 깨움

표적이 같은데 임상에서는 완전히 다른 약처럼 행동함. 답은 혈장 동태(plasma kinetics)가 아님. 혈장 반감기 \(t_{1/2}\)만 봐서는 절대 못 맞춤 — 진짜 답은 약이 "작용하는 곳"으로 건너갔다 떠나는 다리의 통행 속도가 100배 다르기 때문임. 이 통행 속도의 이름이 \(k_{e0}\)인데, §5에서 정식으로 만남.

💡 학생 vs 마스터의 5초

지연이 보이면 학생은 손이 먼저 \(k_{e0}\)로 감("효과구획 붙이면 되겠네"). 마스터는 정반대 — "지금 늦는 게 누구냐?"를 먼저 묻고, 답이 나온 다음에야 식 모양을 고름. 이 강의가 가르치는 건 그 5초의 사고 순서임.

🎯
가장 충격적인 임상 장면으로 "농도만 봐선 효과를 못 맞춘다"를 몸으로 느끼는 자리. 다리문장: 그전에 초보가 가장 잘 빠지는 함정 — "단위가 같으면 의미도 같다"는 착각부터 깔자.
§3 · 함정같은 단위라고 같은 의미가 아님 (PD21)

세 속도상수, 같은 단위 다른 시계

PD21 — 토끼에 길항제 X를 경구 투여. 세 속도상수가 보고됨 G&W p.845:

\[ \overbrace{k_{e0}=0.025}^{\text{생체상 평형}},\quad \overbrace{k_{out}=0.031}^{\text{시스템 회전}},\quad \overbrace{k_{off}=0.018\ \text{min}^{-1}}^{\text{수용체 해리}} \]

세 값이 거의 비슷하고 단위도 셋 다 \(\text{min}^{-1}\)(분의 역수 = "1분당 몇 번")으로 같음. 초보는 "어차피 다 비슷한 시간상수네" 하고 넘어감 — 이게 함정임. 셋은 완전히 다른 시계를 가리킴:

기호비유실제 의미어느 막?
\(k_{e0}\)다리 통행 속도혈장→작용부위로 건너가는 속도2막
\(k_{out}\)수조 배수 속도시스템이 반응을 만들고 비우는 속도3막
\(k_{off}\)빗장 풀림 속도약물-표적 결합이 풀리는 속도수용체 결합
🔢 해리 반감기 직접 계산

\(k_{off}=0.018\ \text{min}^{-1}\)이면 결합이 절반 풀리는 반감기 \(=\ln 2/k_{off}=0.693/0.018\approx38.5\)분 (G&W는 39분으로 반올림 G&W p.845). 같은 식으로 \(k_{e0}\)≈28분, \(k_{out}\)≈22분. 비슷해 보여도 가리키는 물리적 대상이 다름.

한 줄 결론세 값이 비슷한 건 우연이지 동치가 아님. 단회투여(single-dose)만으론 어느 시계가 율속인지 못 가림 — 용량 층화·반복투여·washout 같은 풍부한 설계가 필요 G&W p.846. 다리·수조·빗장, 끝까지 따라옴.
§4 · 1막Hysteresis 방향 = 결론이 아니라 필터

고리 방향은 단서지 판결이 아님

이력현상(hysteresis) = 농도가 오를 때와 내릴 때 반응이 다른 경로를 따르는 현상. 농도-반응을 시간 순서로 이으면 고리(loop)가 생김.

Digoxin (강심제)

IV bolus 후 첫 4시간, 혈장 농도는 감소하는데 심장 효과는 증가 — 약이 심장 조직으로 늦게 드는 분포 지연. 그래서 약 6시간 뒤 측정해야 함 R&T Fig.8-1, p.234.

Naproxen (NSAID)

경구 500mg 후 치통 완화에서 명확한 반시계(CCW) 고리 — 약 5시간 뒤에야 반응이 농도 하강을 따라감 R&T Fig.8-2, pp.234–235.

방향1차 해석후보(hidden state)검증 단서
CCW 반시계반응이 농도보다 늦음분포 지연·회전·느린 결합·동조성 대사체용량 무관 \(t_{max}\)? · loop collapse · 반복투여
CW 시계반응이 일찍 약화내성·길항성 대사체·수용체 감소반복투여 trough · washout 후 rebound
🔬 Loop collapse · ⚠️ Input-rate artifact

측정 농도 \(C\) 대신 추정 \(C_e\)로 다시 그렸을 때 고리가 한 곡선으로 접히면(collapse) 분포 지연이 율속 — 가장 깨끗이 접는 \(k_{e0}\)가 추정치 R&T Fig.8-14, pp.245–246. ⚠️ 단, 매우 빠른 IV bolus는 진짜 내성이 아닌데도 CW를 만듦(주입속도 아티팩트) — 더 느린 주입으로 재확인 R&T p.236; G&W p.296.

"같은 농도를 두 번 방문했을 때 두 번째에 더 환영받으면 CCW, 덜 환영받으면 CW."

§5 · 2막약물 시계 \(k_{e0}\) — 다리 통행 속도

딱 한 줄만 외우면 됨 — 효과구획 ODE

혈장 농도 \(C(t)\)는 측정되지만 약이 실제로 작용하는 곳(effect site·biophase)의 농도 \(C_e\)는 측정 안 됨. 거기로 가는 길에 시간이 걸려 CCW 고리가 생김. \(C_e\)는 반응 곡선으로 역추정되는 숨은 상태 G&W p.263.

\[ \underbrace{\frac{dC_e}{dt}}_{\text{Ce 변화율}}=\underbrace{k_{e0}}_{\text{추종 속도}}\left(\overbrace{C}^{\text{혈장 농도}}-\overbrace{C_e}^{\text{생체상 농도}}\right) \]

읽는 법: "효과부위 농도는 혈장과의 차이(\(C-C_e\))에 비례해 변한다." 차이가 크면 빨리 따라가고 줄면 천천히. \(k_{e0}\)가 크면 골목 문이 활짝 열려 금방 같아지고, 작으면 한참 늦음. 좋은 점 — 구동 함수 \(C(t)\)에 뭘 넣든 작동함(선형·비선형 PK, 심지어 관측값을 그대로 꽂는 table function). 그래서 NONMEM이 깔끔하게 받음 G&W p.269; PD21 pp.840–842.

이 \(C_e\)를 약효 식(Hill = sigmoid \(E_{max}\))에 넣어 반응을 계산함 G&W Eq.3:141, p.268:

\[ E = E_{max}\cdot\frac{C_e^{\,n}}{EC_{50}^{\,n}+C_e^{\,n}} \]
\(EC_{50}\) 최대효과 절반을 내는 농도 = 효력 \(n\) Hill 지수 = S자의 가파름 역사 Segre·Wagner(1968)·Sheiner(1979) G&W Fig.3.52, p.262
⚠️ 닫힌 해의 단순화 가정 두 개

IV bolus+1구획일 때 닫힌 해는 \(k_{1e}=k_{e0}\)와 \(K_p=1\)(평형에서 \(C_e=C\))을 깔고 있음 G&W pp.263–265. 보편 물리법칙이 아님 — 두 파라미터를 따로 못 떼는 식별성 문제 때문의 표준 단순화임. 약이 생체상에 더 농축되면 \(K_p\ne 1\).

§5 · 2막평형 반감기 · 용량 무관 \(t_{max}\)

마취과 의사가 외우는 그 시간

일정 농도(step input)를 넣으면 \(C_e\)가 평형 도달하는 반감기가 한 줄로 떨어짐 — "새 용량의 효과는 언제 시작되나?"의 답은 혈장 \(t_{1/2}\)가 아니라 이것 G&W p.269:

\[ \overbrace{t_{1/2,\,k_{e0}}}^{\text{생체상 평형 반감기}} = \frac{\ln 2}{k_{e0}} \]

🔑 가장 강력한 진단약물 동태가 선형(linear)이면 효과구획 모델은 용량이 커져도 \(t_{max}\)(반응 peak 시각)가 똑같다고 예측 G&W p.264. 5/45/225 µg/kg 세 곡선 peak가 다 8시간 근처면 → link 지지(PD20 G&W Fig.20.2, p.839). 단, "\(t_{max}\) 다름"은 link 기각이지 turnover 확정은 아님(turnover는 양쪽 다 가능).
§5 · 2막☠️ 가장 위험한 함정 — EC50 용량 분기

수렴은 했는데 생물학이 헛소리

G&W §3.9.7의 유명한 실험 — 회전(turnover)으로 만든 데이터를 억지로 effect compartment에 끼워 맞춤. 세 용량을 따로 피팅했더니 \(EC_{50}\)이 이렇게 튐 G&W Table 3.10, p.271:

\[ \overbrace{\text{dose 1: } EC_{50}=0.681}^{\text{저용량}} \quad\to\quad \overbrace{\text{dose 10: } EC_{50}=4.85}^{\text{중용량}} \quad\to\quad \overbrace{\text{dose 100: } EC_{50}=0.941}^{\text{고용량}} \]

용량 사이에 \(EC_{50}\)이 약 7배 출렁임. (원래 데이터를 만든 turnover의 진짜 값은 \(k_{out}=0.024\), \(EC_{50}=0.164\).) 게다가 셋을 동시 피팅하면 곡선이 전부 같은 시각에 peak를 찍어 데이터보다 일찍 솟음. 수용체가 용량 따라 7배 민감해진다는 건 말이 안 됨 — Link 모델이 회전/적응 misspecification을 강제로 흡수하는 것임 G&W p.272.

⚠️ 인용 주의 + 경계 사례

Fig.3.59·Table 3.10은 PD12 데이터임 — PD13이 아님! · 그리고 Succinylcholine의 "근마비 회복 4분"은 용량-지속시간 예시지 효과구획 평형 반감기가 아님 — Table 3.9의 "근마비 4분"과 숫자만 같고 가리키는 양이 다름 R&T Fig.8-18·8-24, pp.249–256.

한 줄 결론CCW + 선형 PK + 용량 무관 \(t_{max}\) + 단일 \(k_{e0}\)로 깨끗한 loop collapse → 효과구획 가설 생존. 하나라도 흔들리거나 \(EC_{50}\)이 용량 따라 출렁이면 → 다른 숨은 상태가 link 뒤에 숨었다는 신호 → 3막으로. (§10 Signature 1)
§6 · 3막시스템 시계 — 수조 + 자동조절기

월요일 두통, 일요일 협심증

니트로글리세린(혈관확장제)을 다루는 모자 공장 작업자의 한 주 — 내성과 반동이 한 사람 안에 다 나타남 G&W pp.284–286:

시점증상정체
월요일(첫날)심한 두통 (뇌혈관 확장)효과 full
화~금두통 점점 줄어듦내성(tolerance) 발달
일요일(노출 끊김)기저선 넘어선 혈관 수축 → 협심증 비슷반동(rebound)
다시 월요일두통 재시작(주말엔 모자에 발라뒀다 함)

두 현상이 따로가 아니라 같은 ODE 쌍의 두 국면(phase)임. 핵심은 — 약이 사라져도 시스템이 노출의 흔적을 한동안 기억함. 그 기억이 내성을 만들고, 같은 기억이 반동을 만듦.

💡 욕조 + 자동온도조절기

욕조에 수도꼭지(\(k_{in}\))로 물이 들고 배수구(\(k_{out}\))로 빠짐. 약은 수도꼭지를 더 트는 자극. 그런데 수위가 오르면 뒤늦게 배수구를 더 여는 자동조절기가 하나 더 달려 있음 — 이게 조절자 \(M\)임. 약을 끊어도 \(M\)은 아직 높이 올라가 있어 배수를 세게 함 → 수위가 기저선 아래로(반동).

⚠️
혼동쌍 — 내성 vs 반동은 다른 두 기전이 아님. 약 있을 때 효과 깎는 국면=내성, 약 끊은 뒤 \(M\)이 남아 미는 국면=반동. 헷갈리면 "수조에 조절기 하나"로 돌아오면 됨.
§6 · 3막조절자 ODE · 음의 되먹임

시스템 기억을 두 줄로

반응 \(R\)(수조)와 그 뒤를 따라오는 조절자 \(M\)(자동조절기), 두 식이 필요함 G&W Eq.3:193–194, p.299:

\[ \underbrace{\frac{dR}{dt}}_{\text{R 변화율}}=\overbrace{k_{in}\,S(C)}^{\text{자극 입력(수도꼭지)}}-\overbrace{k_{out}\,M}^{\text{조절기가 키운 배수}} \]
\[ \underbrace{\frac{dM}{dt}}_{\text{M 변화율}}=\underbrace{k_{tol}}_{\text{적응 속도}}\left(\overbrace{R}^{\text{현재 수위}}-\overbrace{M}^{\text{지연된 조절기}}\right) \]

\(S(C)\)=약물 자극 함수(약 없으면 1, 있으면 1보다 커져 생성↑, 무차원). 둘째 식은 \(k_{e0}\) ODE와 똑같은 "차이에 비례" 꼴 — 다리 ODE를 봤으면 거저임.

⚠️ 부호가 음수여야 하는 이유

\(M\)이 \(-k_{out}M\)로 들어가는 건 임의가 아님 — 부호가 \(+\)면 자기증폭해 무한 발산(시스템 폭주). 음의 되먹임(negative feedback) 한 글자가 항상성(homeostasis)을 만드는 유일한 구조 G&W pp.297–298.

🔢 자극 크면 겉보기 반감기 짧아짐

겉보기 반감기 \(t_{1/2,k_{out}}=\dfrac{\ln 2\,R_0}{k_{in}\,S(C)}\) G&W Eq.3:204, p.299. 분모에 \(S(C)\) — 고용량일수록 같은 상수인데도 시간척도가 짧아짐. \(S(C)\) 2→10이면 반감기 약 5배 단축("고용량에서 내성이 빨리 보이는" 정체).

🔬 AUC 비대칭 — 내장된 시그니처

약 주는 동안 효과 면적이 끊은 뒤 반동 면적보다 큼 G&W Fig.3.82, p.298: \(\,AUC_R<AUC_E\,\). 만약 \(AUC_R\approx AUC_E\)(대칭)면 조절자 구조 설정이 의심됨(또는 pool/precursor 쪽). 비율 0.3이면 전형적 조절자.

§7 · 4막신호 시계 \(n\times\tau\) — 릴레이 경주

단거리가 아니라 이어달리기

1차 ODE 하나(단일 link)는 단거리 — 출발 총성에 곧바로 최대 속도. 여러 1차 ODE 연쇄(transit chain)는 릴레이 — 바통이 마지막 주자에 갈 때까지 결승선 반응이 느리게, S자로 나타남.

출발 기울기 한 차이
단거리 (n=1):   t=0에서 최대 기울기  → 부드러운 지수 접근
릴레이 (n=3):   t=0에서 기울기 ≈ 0   → 지연된 S자(sigmoid) 상승

약물 자극을 받는 첫 단계 + 바통 넘기는 단계들 + "관찰값은 맨 끝"이라는 세 줄 G&W Eq.3:257–259, pp.323–325:

\[ \underbrace{\frac{dR_e}{dt}}_{\text{Re 변화율}}=\underbrace{\frac{1}{\tau}}_{\text{단계 전달속도}}\left(\overbrace{E_0\,S(C)}^{\text{목표 반응}}-\overbrace{R_e}^{\text{현재 Re}}\right) \]
\[ \underbrace{\frac{dR_i}{dt}}_{\text{Ri 변화율}}=\underbrace{\frac{1}{\tau}}_{\text{단계 전달}}\left(\overbrace{R_{i-1}}^{\text{앞 주자}}-\overbrace{R_i}^{\text{현재 주자}}\right),\quad \underbrace{R_{obs}=R_n}_{\text{관찰=맨 끝}} \]
🦴 척추 호출 — 2막 vs 4막

여기서 늦는 건 약물의 이동이 아니라 반응 신호의 전달임. 2막은 "약이 부위에 도달했는가", 4막은 "신호가 측정 지점에 도달했는가" — 서로 다른 질문, 다른 숨은 상태. 보통 회전 모델로 못 잡는 15–20시간 onset 지연이 여기 영역 G&W Fig.3.98–3.99, p.323.

⚠️ \(n\times\tau\)는 정확히 상수가 아님

"\(n\tau\)는 trade-off라 상수"는 오해. 위 표에서 \(MTT\)가 \(n{=}1\to5\)로 가며 20→32시간, 약 60% 단조 증가함. \(n\)이 커질수록 초기 lag가 커져 평균 지연을 약간 더 늘려야 onset이 더 S자가 됨. 민감도·기저(\(EC_{50}\)≈0.35, \(E_0\)≈15–20)는 안정한데 시간 구조만 재배치.

한 줄transit chain은 지연의 크기가 아니라 모양(형상)을 만듦. WRSS가 평탄해지는 곳에서 \(n\) 선택 종료 — "데이터가 해상하는 것 이상을 주장"하지 말 것.
§7 · 4막임상 응용 · 효력 차원 확장

릴레이가 임상 표준이 되는 자리

Friberg–Karlsson 골수억제 모델 교과서 외 · J Clin Oncol 2002

항암제 호중구 감소·회복의 표준 PD 모델이 정확히 transit chain 골격 위에 있음 — 골수 전구세포 → 3단계 성숙 transit chain → 순환 호중구. 핵심 증식 식 하나에 이 강의 도구가 다 들어감:

\[ \underbrace{\frac{dProl}{dt}}_{\text{골수 전구세포}}=\overbrace{k_{prol}\,Prol\left(1-\underbrace{E_{drug}(C)}_{\text{세포살상}}\right)\left(\frac{Circ_0}{Circ}\right)^{\gamma}}^{\text{생성: 자기증식 × 약물억제 × 음의 되먹임 보상}}-\underbrace{k_{tr}\,Prol}_{\text{다음 단계로}} \]

Transit \(n\times\tau\)=4막 · 음의 되먹임 \((Circ_0/Circ)^{\gamma}\)=3막 조절자 직관 · 간접반응 \(k_{prol}\) vs \(k_{circ}\)=11번 세션 · 자극 함수 \(E_{drug}(C)\)=Hill. 약이 바뀌어도 사슬 구조는 유지되고 세포살상 항만 달라짐 — 신호 시계는 약물이 아니라 시스템에 속함.

확장 — Black–Leff Operational Model 교과서 외 · Proc R Soc 1983

transit chain이 시간 차원 신호전달이면, operational model은 효력 차원. 여기 \(\tau\)는 transducer ratio(무차원 효력 지표) — ⚠️ transit chain의 \(\tau\)(시간)와 기호만 같고 의미 완전 다름(§3 함정 반복!).

\[ \overbrace{EC_{50}^{obs}\big|_{n=1}}^{\text{Hill }n=1\text{ 관찰 EC50}} = \frac{\underbrace{K_A}_{\text{실제 친화도}}}{\underbrace{1+\tau}_{\text{효력 보정}}} \]

완전 작용제(\(\tau\gg1\))면 \(EC_{50}^{obs}\to K_A/\tau\)로 매우 작아짐. onset 모양이 안 맞으면 transit chain, 점근선 높이(\(E_{max}^{obs}<E_m\))가 안 맞으면 operational \(\tau\) — 경쟁이 아니라 직교 차원.

§9 · 도구NONMEM — 줄 수 = 숨은 상태 개수

모델 선택이 어렵지, 코딩은 받아쓰기

NONMEM = NONlinear Mixed Effects Modeling = 비선형 혼합효과 모델링. 비선형(Hill 곡선) + 혼합효과(집단 공통 고정효과 + 개인 변이 임의효과)를 한 모델에 섞어 추정하는 인구집단 PK/PD 표준 프로그램임.

💡 주방기계 비유

ODE가 "레시피"라면 NONMEM은 재료(데이터) 넣고 레시피대로 돌려 양념 비율(파라미터 \(k_{e0}\)·\(k_{tol}\)·\(\tau\))을 역으로 알아내는 주방기계임. 레시피는 우리가 §1–8에서 골랐고, 기계 돌리는 게 NONMEM 몫.

effect compartment — DADT 한 줄 + Hill 한 줄
$DES

5 단일 link vs transit단거리(출발 기울기 최대) vs 릴레이(출발 기울기 0). 이 한 차이가 onset 모양 전부
🔬 Pair 1 확장 — 약물-표적 체류시간

교과서 외 · Copeland 2016 \(k_{off}\)를 해리 속도로만 좁히면 현대 신약개발 맥락을 놓침. 체류시간 \(\bar{t}_R=1/k_{off}\) = 혈장 동태가 끝난 뒤에도 약이 표적에 머무는 평균 시간. PD21의 \(k_{off}=0.018\)이면 \(\bar{t}_R\approx56\)분 — 공유결합·알로스테릭 억제제의 혈장 무관 지속 효과의 출발점. 3막 \(M\)(시스템 기억)과 다른 종류의 약물-표적 결합 기억임.

참고: 내성 vs 반동은 혼동쌍이 아님 — 같은 조절자 방정식의 두 국면(§6에서 정착). 그래서 Pair 4는 내성 vs 적응을 다룸.

새 데이터 받으면 5초 안에 하는 일

← 이전 11번(간접반응)

3막 조절자 = 11번 골격 \(dR/dt=k_{in}S(C)-k_{out}R\)에 \(M\) 한 칸 더 단 것. 11번 없이는 3막·감별표가 안 섬.

다음 13번(개인차·공변량) →

9장 "혼합효과"의 임의효과가 13번 본론. 12번에서 숨은 상태를 잘못 명명하면, 13번에서 변이를 엉뚱한 파라미터에 떠넘김.

새 PK/PD 데이터를 받으면 — 네 숨은 상태 중 어느 게 작동 중인지를 수식 쓰기 전에 결정함:

네 숨은 상태1막 loop 방향 = 후보 좁히는 게이트(필터) · 2막 생체상 \(C_e\) = 다리 · 3막 조절자 \(M\) = 수조+조절기(약물 구획 아님) · 4막 신호 단계 \(R_1\ldots R_n\) = 릴레이. ODE 선택은 결과이지 시작이 아님.

"A delay is not a mechanism. Name the delayed state.
지연은 메커니즘이 아니다. 지연되는 상태에 이름을 붙여라."

한 줄 요약: 농도-효과 어긋남은 숨은 상태가 끼어서임. 그게 분포(\(k_{e0}\)·다리)·신호(\(n\times\tau\)·릴레이)·내성(조절자 \(M\)·수조+조절기) 중 누구인지를 용량 의존성·hysteresis 방향·반복투여 carry-over로 가려냄. ODE는 그 이름을 붙인 다음에 고른다.

§13자가점검 · 풀고 답 확인

손에 붙었는지 확인

Q1감별 CCW hysteresis가 보임. 곧장 effect compartment를 붙여도 되나?
안 됨. 방향은 후보를 좁히는 필터지 판결이 아님. 같은 CCW를 분포·신호·회전이 다 만듦. ① 선형 PK 하 용량 무관 \(t_{max}\)+단일 \(k_{e0}\) loop collapse(2막), ② 반복투여 trough drift·반동(3막), ③ 늦은 S자 onset(4막)을 추가로 확인해 가려야 함.
Q22막 Fentanyl(6.4분)과 가상의 약(0.7분), 어느 쪽이 효과가 빨리 시작되나?
\(t_{1/2,k_{e0}}=\ln 2/k_{e0}=0.693/k_{e0}\) G&W p.269. 반감기가 짧을수록 빨리 평형 = 빨리 onset. 0.7분짜리가 약 9배 빨리 시작. (혈장 반감기가 아니라 이 평형 반감기가 timing을 결정.)
Q33막 PD13에서 \(k_{tol}=4.2>k_{out}=2.9\). AIC 빼고, 이 부등식 하나가 왜 결정적인가?
내성 속도(\(k_{tol}\))가 회전 속도(\(k_{out}\))보다 빨라야 단 한 번 주입 안에서도 조절자 \(M\)이 따라잡아 효과를 깎음. 또 2번째 trough가 1번째로 reset되지 않는 carry-over를 만듦. Model III의 \(k_{tol}=0.05\)는 너무 느려 비현실적 G&W p.808.
Q44막 PD35 WRSS \(1319\to789\to642\to632\to682\). WRSS 최소라고 \(n=4\)를 고르면 왜 안 되나?
\(n=4\) 개선은 미미(642→632)하고 \(n=5\)에서 악화(632→682) — \(n=3\) 부근에서 정보 한계 도달(Sig 4). \(n\)은 생물학 단계 수가 아니라 데이터가 해상하는 깊이. 절약 원칙상 \(n=3\). \(n=4\)를 "더 좋다"는 건 데이터가 해상하는 것 이상을 주장하는 것 G&W p.914.
Q5R&T 앵커 Acenocoumarol(\(t_{1/2}\)≈15h)과 phenprocoumon(≈6일)은 같은 쿠마린계인데 회복 시간이 한 자리수 차이. 각 회복을 율속하는 단계는?
회복은 (i) 약물 제거와 (ii) 응고인자 회전 중 더 느린 과정이 율속 R&T pp.236,246. Acenocoumarol: 약물이 빨리 빠져(15h) 회복이 응고인자 회전(동역학)에 제한. Phenprocoumon: 약물 자체가 가장 느려(6일) 회복이 약물 동태에 제한. (Warfarin은 ≈1.5일로 경계라 적정이 까다로움.)
